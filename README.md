### 🚀 Featured Projects

Here are some of the active projects I am building and maintaining:

*   **[QuickText](https://github.com/BlazeR-28/QuickText)** – A premium standalone C# WPF note-taking WebView2 application. Features customizable global and local shortcuts, adjustable layered window opacity via native Win32 interop, autosave/restore, and a fully polished Settings panel.
*   **[OmniUp (V6)](https://github.com/BlazeR-28/OmniUp)** – A modern C# WinUI 3 desktop client designed to manage and perform global system updates utilizing `winget`. Features a custom sidebar layout and sleek dark mode desaturated visuals.
*   **Local Web Hosting Suite** – A Docker-based development environment mapping wildcard domains (*.blazer, *.localhost) to subfolders using Traefik v3 and a custom Nginx container, bound to ports 80/443.
*   **Handy App** – An offline speech-to-text dictation client for Windows, integrating Ollama with `gemma2:9b` to automatically process transcriptions (correct grammar, remove filler words) in the background.
